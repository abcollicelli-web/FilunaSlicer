# Filuna — direção visual C / inventário consolidado

**123 pranchas estáticas em 11 famílias; 208 linhas rastreadas.** Os dois modelos C aprovados foram preservados byte a byte. Todas as outras composições são propostas em revisão. Não há implementação nem homologação funcional.

## O que está pronto
- Seis abas principais; 26 cenários Dispositivo + aquecimento; 22 geradores com variantes visíveis; galeria em três segmentos; dez tutoriais e seis submenus de calibração; editores/menus da Preparação; ferramentas e auxiliares; web futuro separado e OFF.
- 205 linhas do lote recebido consolidadas, mais três continuações explícitas: nenhuma linha sem PNG/SVG. Detalhes normativos não confirmados permanecem marcados; não se afirma inventário universal do software.
- Capas autorais demonstrativas substituem placeholders de estudo; a implementação deverá usar as capas reais do catálogo.
- G2/G3 BLOCKED · G4 NOT RUN · G5/G6 BLOCKED. Nenhum código de aplicativo, CI, build, conta, hardware, servidor ou website alterado.

## Como interpretar
PNG e SVG medem 2880×1920. SVGs usam assets locais relativos, sem dependência remota. Manter as pastas assets e fontes junto às famílias. Inter é distribuída com licença OFL. Peças, render de câmera e capas são ilustrações autorais, nunca frames de OEM ou dados medidos.
A matriz informa coordenadas no viewBox 1920×1280, não nos pixels finais 1,5×. Em geradores, o render principal demonstra prévia; a faixa inferior mostra entrada vazia/nome, geração, falha e arquivo válido. Estados propostos não são comportamento executado.
Contratos detalhados ainda não confirmados estão anotados por linha; campos numéricos sem domínio normativo são amostras, não padrões oficiais. Home/galeria não alteram o catálogo publicado.
Histórico do lote parcial está preservado em producao/; ele não é a cobertura desta revisão.
